\#  Java Analog Clock GUI



A real-time desktop analog clock application developed in Java using Swing and AWT Graphics2D rendering.



\---



\##  Overview \& Features



\* \*\*Real-Time Rendering:\*\* Dynamically updates clock hands using system time and Java event loops.

\* \*\*Vector Graphics:\*\* Utilizes Java `Graphics2D` with anti-aliasing enabled for smooth geometric hand rendering.

\* \*\*Trigonometric Math:\*\* Computes exact hand angles using custom coordinate transformations for second, minute, and hour hands.



\---



\##  Tech Stack \& Concepts



\* \*\*Language:\*\* Java (JDK 8+)

\* \*\*GUI Toolkit:\*\* Java Swing, AWT

\* \*\*Rendering \& Design:\*\* `Graphics2D`, Trigonometric Vector Math, Event-Driven Programming

\* \*\*Tools:\*\* VS Code / Eclipse / NetBeans, Git
